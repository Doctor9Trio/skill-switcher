Why Bottom-Left Gear Only Showed GitHub

In recent updates, Google decoupled the VS Code editor shell from the Antigravity AI Agent runtime:

1
Bottom-Left Account Icon: Strictly manages your standard VS Code accounts (GitHub, Microsoft Sync). It does not control your Google model quota or Antigravity license.
2
Chat /logout Command: /logout is not an Antigravity slash command (slash commands are prompt workflows like /plan or /goal). Typing it sends text to the AI rather than logging out.
3
Nuclear state.vscdb Deletion: Deleting storage files destroys open tabs, recent workspaces, and editor layout. Skill Switcher solves this by targeting only the OAuth token files cleanly.

Where Native Sign Out & Chrome Login Live

To sign out directly through the official Antigravity IDE UI and trigger Google Chrome:

A
Press Ctrl + Shift + P (Command Palette) → Type: Antigravity: Open Antigravity Settings.
B
In the settings sidebar, select the Account tab.
C
Under Email, click Sign Out. The button immediately turns into a blue Sign In button. Click it, and Chrome opens to accounts.google.com so you can pick your target account!
Pro-Tip: Using Skill Switcher's 1-Click Vault eliminates the need to sign out or re-authenticate in your browser every time!
