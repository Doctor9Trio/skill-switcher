Master Guide: How to Use JEV, MCP & Design Skills
⚡ The Core Concept of JEV: Traditional frontier LLMs (Claude 3.5, GPT-4o) are slow (3–8s per turn) and costly for repetitive operations like verifying button clicks, validating schema transitions, or checking code diffs. JEV (JSON-Evaluated Vectors) implements sub-50ms deterministic local decision loops that run instant evaluations before delegating back to the main agent.

When to use JEV skills:

  • Autonomous UI Testing: browser-use/jev-ultrafast emits verified DOM actions (Click, Type, Scroll) without waiting for LLM round-trips.
  • Context Compaction: fast-jev-compaction compresses conversational logs and AST trees before hitting context token ceilings.
  • Autonomous Code Decision: semdecide and Winnow discard dead architectural options deterministically using discrete logic gates.
  • Data Cleaning: jev-curate scores thousands of telemetry and training rows per second without expensive token burn.

In Antigravity IDE, you trigger skills using standardized syntax in your chat:

🔌 Model Context Protocol (MCP): MCP allows Antigravity IDE to invoke external tools (desktop controllers, graph databases, design systems) as native agent tools.

Connecting MCP Skills in Antigravity IDE:

  1. Open your global MCP config at: ~/.gemini/antigravity-ide/mcp/
  2. When you activate typesafe-mcp or jev-mcp, Antigravity generates type definitions and tool declarations automatically.
  3. The agent will see tools prefixed with mcp_* (e.g. mcp_typesafe_verify or mcp_appllama_inspect).
